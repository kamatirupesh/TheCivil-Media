THE CIVIL MEDIA — NEWS PORTAL

This package contains the responsive public news website and a browser-based Admin CMS.

ADMIN FIRST-USE SETUP
1. Open the website and choose CMS.
2. On first use, create your own admin username and password.
3. The project does not ship with a preset admin username/password.
4. After setup, use Admin CMS > Admin account to change the login.

CMS FEATURES
- Dashboard with article counts
- Add, edit, publish, draft, archive, search and delete news
- Bilingual English/Nepali article fields
- Image URL and browser image upload support
- Company settings, logo, colors, fonts, page style and social-media URLs
- Advertisement manager: add/edit/enable/disable/delete ads, upload ad images and set click-through URLs
- Header, sidebar and footer advertisement placements
- Subscriber and contact-message storage in the browser
- Responsive mobile layout

SOCIAL MEDIA LINKS
Enter complete Facebook, YouTube, Instagram or X URLs in Company settings. Public-site social links open the configured destination in a new tab.

DATA / SECURITY
This prototype stores articles, settings and credentials in browser localStorage. It is not production authentication. For a public deployment, move authentication, passwords, articles and media to a server/database and hash passwords server-side.

FILES
- index.html — entry page
- styles.css — responsive styling
- app.js — public site + CMS logic
- assets/logo.jpeg — supplied Civil Media logo

Nepali date
-----------
Published dates and the current site date now show Bikram Sambat (BS) alongside the Gregorian date. The current calendar table covers BS 2083 (14 April 2026 through 13 April 2027), including Nepali month names and dates. The conversion uses per-month calendar data because Bikram Sambat month lengths vary by year.
